제품 릴리즈 히스토리

Alpha Viper System은 베타 단계에서 엔진, 알림, 라이선스, 포트폴리오 기능을 순차적으로 검증한 뒤 정식 V1.0으로 통합했습니다.

Current Release

Alpha Viper System [QUANT ENGINE] · V1.0 정식

정식 V1.0은 자동매매 엔진 고도화, 포트폴리오 운영 화면, 리스크 기준, 거래 로그, 설치·라이선스 운영 체계를 정리한 공식 릴리즈입니다. 베타 단계의 실험 기능을 실제 운용 흐름에 맞게 다듬고, 화면 구성과 사용 절차를 단순화했습니다.

릴리즈 기준현재 홈페이지와 고객 패키지는 V1.0 정식 버전을 기준으로 안내합니다.
운영 범위데이터 수집, 포트폴리오 점검, 주문 감시, 알림, 로그 확인, 라이선스 관리를 포함합니다.
문의 방식도입, 설치 지원, 고객 패키지 제공, 라이선스 발급은 이메일 문의를 기준으로 진행합니다.
