1. 적용 범위와 문의

이 방침은 잉글리쉬카드의 영어 어휘 학습 기능에 적용됩니다. 개인정보 관련 문의와 열람·정정·삭제 요청은 help@alphavipertrading.com으로 접수할 수 있습니다. 문의에 비밀번호나 신분증을 첨부하지 마세요.

2. 기기에 보관하는 정보

입력한 이름 또는 별명과 나이, 즐겨찾기 단어, 학습 위치와 진도, 음성 선택·속도·소리 설정을 사용 중인 기기의 앱 저장소 또는 브라우저 저장소에 보관합니다. 나이는 추천 과정을 정하는 데 사용하며 실명 대신 별명을 입력할 수 있습니다. 웹 버전과 Android 버전에 따라 저장 항목과 유지 방식에 차이가 있을 수 있습니다.

잉글리쉬카드 자체 회원가입, 서버 프로필 저장 또는 기기 간 계정 동기화 기능은 없습니다. 이름·나이·즐겨찾기·학습 진도를 운영 서버로 전송하는 기능은 포함하지 않습니다.

3. 음성 합성과 네트워크

발음 재생은 Android 또는 브라우저의 음성 합성 기능을 이용합니다. 선택한 음성이 인터넷 연결을 필요로 하면 읽을 영어 단어나 문장이 해당 음성 제공자의 서비스에서 처리될 수 있습니다. 음성 제공자의 데이터 처리에는 해당 제공자의 방침이 적용됩니다. 프로필 이름과 나이를 발음 서비스로 보내는 용도로 사용하지 않습니다.

음성 설정에서 기기 내장 음성을 선택하거나 소리를 끌 수 있습니다. 앱은 사용자의 목소리를 녹음하지 않으며 마이크, 카메라, 위치 또는 연락처 권한을 요구하지 않습니다. 웹 버전·공개 방침·외부 링크를 열 때에는 호스팅 사업자에게 접속 IP와 요청 시각 등 통신 정보가 전달될 수 있습니다.

4. 보유 기간과 삭제

기기 내 기록은 사용자가 앱 데이터 또는 브라우저 사이트 데이터를 삭제할 때까지 남을 수 있습니다. Android 설정의 앱 > 잉글리쉬카드 > 저장공간 > 데이터 삭제에서 지울 수 있습니다. 앱 제거, 브라우저 데이터 정리 또는 기기 변경으로 학습 기록이 사라질 수 있습니다. 운영자는 기기에만 저장된 학습 기록을 원격으로 조회하거나 복구할 수 없습니다.

문의 이메일을 직접 보내면 회신 주소와 문의 내용은 답변 및 해당 문제 처리에 사용됩니다. 문의 기록 삭제를 요청할 수 있으며, 보존이 필요한 사유가 있으면 그 범위와 이유를 안내합니다. 음성·호스팅 사업자의 통신 기록은 해당 사업자의 보유 기준을 따릅니다.

5. 광고, 아동 및 변경 안내

현재 확인한 앱에는 광고 SDK, 광고 ID 수집 또는 학습 기록의 자동 분석·오류 보고 업로드가 포함되어 있지 않습니다. 어린이가 이용할 때에는 보호자가 기기·음성 제공자 설정과 저장 정보 삭제 방법을 함께 확인해 주세요. 계정·광고·서버 동기화 등 데이터 처리 방식이 변경되면 방침을 갱신하고 필요한 안내와 동의를 제공합니다.

이 문서는 잉글리쉬카드에 적용됩니다. 웹사이트 고객문의 개인정보 안내와 적용 대상이 다릅니다.
