1. 적용 범위와 처리자

앱은 계정 가입을 요구하지 않습니다. 앱에서 고른 시·도와 군·구를 사용해 공공 프로그램 목록을 요청하며, 기기의 GPS 위치를 읽지 않습니다. 개인정보 처리와 관련한 문의는 개발자 alphavipertrading의 이메일 help@alphavipertrading.com로 보내 주세요.

2. 기기에 저장하는 정보

앱은 사용자가 입력하거나 선택한 지역, 자녀 연령(선택 입력), 관심 주제, 알림 설정, 관심 프로그램, 최근 검색어, 프로그램 알림 조건과 읽음 상태, 최근 불러온 목록을 앱의 Android 기기 저장소에 보관합니다. 이 정보는 앱 계정이나 개발자 서버에 프로필로 전송되지 않습니다. 자녀 연령 입력은 선택 사항이며 광고 SDK에 전달하지 않습니다.

기기 저장 정보는 앱의 내 정보 → 이 기기의 내 정보 삭제 기능으로 지울 수 있습니다. Android 설정에서 앱 데이터 삭제 또는 앱 제거를 해도 해당 앱 저장소의 정보가 삭제됩니다. 삭제 시 앱이 예약한 로컬 알림도 함께 취소됩니다.

3. 앱 서버로 전송되는 정보

공식 프로그램 검색과 자연어 검색, 사용자가 켠 알림 조건 확인을 요청하면 기능 수행에 필요한 검색어, 선택한 시·도·군·구, 활동 필터, 페이지 번호가 Vercel에서 운영하는 공공시설 AI 똑똑 API로 전송됩니다. 상세 정보 조회에는 공개 프로그램 식별자와 공식 출처 URL이 전송될 수 있습니다. 사용자가 정보 오류 신고를 누르면 프로그램 식별자와 선택한 신고 사유가 전송됩니다. 검색·상세·관심·신청 버튼 사용 이벤트에는 이벤트 종류와 공개 프로그램 식별자가 전송될 수 있습니다. 이름, 이메일, 전화번호, 자녀 이름, 계정 ID는 이 API 요청에 포함하지 않습니다. 검색창에 입력한 문장은 서버로 전송되므로 검색어에 이름이나 연락처 등 식별정보를 입력하지 마세요.

현재 API 운영 설정에서는 사용자 프로필, 검색어, 신고 및 이벤트를 개발자 데이터베이스에 저장하지 않습니다. 요청을 처리하는 호스팅 사업자는 서비스 제공과 보안·장애 대응을 위해 IP 주소, 요청 시각, 기기·브라우저 요청 정보 등 네트워크 로그를 처리할 수 있으며, 그 보유 기준은 Vercel 개인정보처리방침을 따릅니다. 서버 설정이나 기능이 변경되어 저장 항목과 보유 기간이 달라지면 이 방침을 갱신합니다.

현재 운영 검색 API는 질문의 조건을 규칙으로 분석하고 공개 공공기관 목록을 조회합니다. 앱 프로필의 자녀 연령과 관심 설정은 검색 서버로 보내지 않지만, 사용자가 검색 문장에 직접 입력한 내용은 서버로 전송됩니다.

4. 광고 및 제3자 처리

앱은 Google Mobile Ads SDK를 사용해 배너 광고를 표시합니다. 광고 제공, 광고 측정, 진단 및 부정 사용 방지를 위해 Google SDK가 IP 주소, 앱 실행·탭 등 앱 상호작용, 진단·성능 정보, 광고 ID·앱 세트 ID 등 기기 또는 계정 식별자를 자동으로 수집·공유할 수 있습니다. 전송 데이터는 Google Mobile Ads SDK 안내에 따라 전송 중 암호화됩니다. 자세한 내용은 Google Mobile Ads SDK 데이터 공개 안내와 Google 개인정보처리방침을 확인해 주세요.

앱은 아동 대상 광고 요청 설정, G 등급 광고 제한, 비개인 맞춤 광고 요청 및 광고 개인화 비활성화를 적용합니다. 이 설정은 광고 SDK가 서비스 운영·진단·부정 사용 방지를 위해 처리할 수 있는 모든 기기 데이터를 없애는 설정은 아닙니다. 앱의 지역, 검색어, 자녀 연령, 관심 프로그램, 저장 목록은 광고 맞춤 설정에 보내지 않습니다.

앱은 개인정보를 판매하지 않습니다. 공공기관의 신청 페이지를 열면 해당 기관의 사이트가 자체 개인정보처리방침에 따라 정보를 처리합니다. 앱은 외부 신청 페이지에서 제출하는 정보를 수집하지 않습니다.

5. 알림과 외부 공식 페이지

프로그램 알림은 사용자가 알림 권한과 관심 조건을 설정한 경우 기기에서 확인·예약합니다. 현재 앱은 원격 푸시 알림을 사용하지 않습니다. 지역과 관심 조건은 기기 안에서 알림 목록을 거르는 데 사용합니다.

프로그램의 신청·상세 확인을 선택하면 해당 공공기관이 제공하는 HTTPS 공식 페이지를 엽니다. 해당 페이지에 입력한 정보는 그 기관으로 직접 전달되며, 기관의 개인정보처리방침과 이용 조건이 적용됩니다.

6. 보유 기간과 삭제

프로필, 관심 목록, 검색 기록, 알림 조건 및 캐시는 사용자가 앱에서 삭제하거나 Android 앱 데이터를 지우거나 앱을 제거할 때까지 기기에 보관됩니다. API 요청 데이터는 요청 처리에 이용하며 현재 개발자 데이터베이스에 저장하지 않습니다. 호스팅 사업자의 보안·운영 로그는 해당 사업자의 보유 기준에 따라 관리됩니다.

7. 보안, 아동 및 방침 변경

앱과 API 간 통신은 HTTPS를 사용합니다. 앱은 이름이나 연락처 같은 계정 정보를 요구하지 않으며, 자녀 연령과 관심 설정은 기기 안에 저장합니다. Google Mobile Ads SDK의 아동 대상 및 비개인 맞춤 설정을 적용하지만, 광고를 포함한 제3자 서비스의 데이터 처리는 각 사업자의 정책에 따릅니다.

이 방침은 앱 데이터 처리 방식이나 적용 법령이 바뀔 때 갱신됩니다. 변경된 방침과 시행일은 이 페이지에 게시합니다. 개인정보 관련 권리 행사나 질문은 help@alphavipertrading.com으로 문의해 주세요.
