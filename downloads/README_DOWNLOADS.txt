How to register a new public download:
1. Put the AVS ZIP file in downloads/releases.
2. Put or replace manual PDFs in downloads/manuals.
3. Update download.html with the version, date, description, and file path.
4. If deploying through GitHub Releases instead of repository files, replace the file path with the Release asset URL.

Note:
- GitHub repository file uploads have a normal 100 MB limit. Product ZIP files larger than that should be uploaded to GitHub Releases or another download storage.
