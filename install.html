Install Guide

설치 전 확인부터 모의 실행까지 순서대로 점검합니다.

운영 환경에 맞춰 설치, 라이선스 활성화, 계좌/API 설정, 모의 실행을 진행합니다.

01

APK 다운로드

다운로드센터에서 AVS Mobile 최신 APK를 받습니다.

02

설치 허용

Android 안내에 따라 브라우저 또는 AVS의 ‘이 출처의 앱 허용’을 켭니다.

03

AVS 설치

설치를 선택한 뒤 앱을 실행합니다. 기존 설치본은 같은 서명으로 안전하게 갱신됩니다.

04

계좌/API 설정

가상투자로 먼저 확인한 뒤 모의투자 또는 실전투자 계좌를 연결합니다.

05

제품 업데이트

설정의 제품 업데이트에서 신버전을 확인하고 다운로드합니다.

06

설치 확인

다운로드 검증 후 나타나는 Android 설치 화면에서 설치를 선택합니다.
