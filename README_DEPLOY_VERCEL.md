# Alpha Viper System Product Site

정적 HTML 기반 Vercel 배포용 제품 사이트입니다.

## 3.0 홈페이지 반영 사항

- 운영 홈페이지의 제품 버전 표기를 V3.0으로 통일
- 실제 서버 기능이 연결되지 않은 AVS Web 3.0 서비스 진입점 제거
- Windows 최신 설치 패키지를 v4.0 GitHub Release 기준으로 갱신
- 데이터 동기화, 종목 스캔, 계좌 설정이 가능한 웹 서비스는 백엔드 구축 후 별도로 공개

## REV12 반영 사항

- 운영흐름 섹션의 거래로그 이미지에서 실현 손익을 `234,334,200원`으로 수정
- 이미지 캐시 구분을 위해 거래로그 이미지 쿼리 버전을 REV12로 갱신
- 기존 REV11 패키지는 보존하고 REV12 패키지로 별도 생성

## REV11 반영 사항

- 거래로그 이미지에 샘플 체결 데이터를 추가해 빈 화면처럼 보이지 않도록 수정
- 운영흐름 페이지의 “자동화는 일정과 로그가 함께 있을 때 신뢰할 수 있습니다” 섹션 이미지를 거래로그 이미지로 교체
- 거래 이력 요약, 체결 총액, 실현 손익, 최근 체결, 샘플 체결 리스트가 보이도록 이미지 보강
- 기존 REV10 패키지는 보존하고 REV11 패키지로 별도 생성

## REV10 반영 사항

- 신규 홈 메인 화면 이미지 반영
- 홈 메인 하단 포트폴리오 구성 보조 이미지 반영
- 운영흐름 페이지의 AI 운용 스케줄 이미지 반영
- 이미지 캐시 구분을 위해 주요 이미지 쿼리 버전을 REV10으로 갱신

## REV9 반영 사항

- 문의 버튼/문의 양식을 실제 메일 발송 흐름 기준으로 정리
- 문의 제출 중, 성공, 실패 상태 메시지 개선
- 회신 연락처가 이메일 형식이면 메일의 답장 주소로 자동 지정
- 회신 연락처 입력 예시를 `contact@example.com` 형식으로 표시
- 기존 REV8 패키지는 보존하고 REV9 패키지로 별도 배포 파일 생성

## REV8 반영 사항

- 최신 제품 화면 캡처 반영
- 홈페이지 대시보드 이미지 수익률과 실현손익 갱신
- 문의 이메일 직접 노출 제거
- 문의 양식을 `/api/contact` 서버리스 함수로 전송
- 담당자명, 도메인, 가격 정보 제거
- 제품 화면, 기능, 운영 흐름, 보안, FAQ, 문의 페이지 재정리

## 문의 메일 발송 설정

문의 양식은 Resend API를 사용합니다. Vercel 프로젝트의 Environment Variables에 아래 값을 설정해야 실제 메일이 발송됩니다.

- `RESEND_API_KEY`: Resend API 키
- `CONTACT_TO`: 문의를 받을 이메일 주소
- `CONTACT_FROM`: Resend에서 발신 인증이 완료된 발신 주소

환경변수가 하나라도 없으면 `/api/contact`는 성공 처리하지 않고 `MAIL_ENV_MISSING` 오류를 반환합니다. 이 상태에서는 문의 메일이 발송되지 않습니다.

## 로컬 확인

정적 미리보기 서버만 사용하면 서버리스 함수가 실행되지 않을 수 있습니다. 실제 발송 흐름은 Vercel Preview 또는 Vercel CLI 환경변수 설정 후 확인하는 것을 권장합니다.

```powershell
npm i -g vercel
vercel dev
```
